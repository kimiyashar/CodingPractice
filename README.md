# Coding Practice

An archived collection of introductory Java programming exercises created as an Eclipse project in 2022.

## Topics

- One-dimensional and two-dimensional arrays
- Array searching, reversal, and duplicate checks
- Number and digit operations
- Parameter passing
- Card-deck shuffling
- `LightBoard`-style grid exercises

The source code is under `src/org/kimi/`. This appears to be AP Computer Science A-style Java practice rather than CMU 15-112 coursework.
